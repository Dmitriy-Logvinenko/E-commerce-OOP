# Проект E-commerce-OOP

## Описание:

Проект "E-commerce-OOP" - программа для реализации продуктов и их категорий.
Проект содержит классы Category и Product, которые помогают реализовать списки продуктов по категориям.

## Установка:

1. Клонируйте репозиторий:

`git clone git@github.com:Dmitriy-Logvinenko/Project_1.git`

2. Установите зависимости:

`pip install -r requirements.txt`

## Использование:

1. Откройте свой терминал.
2. Запустите проект с помощью команды:

`python src/main.py`
