# Проект E-commerce-OOP

## Описание:

Проект "E-commerce-OOP" - программа для реализации продуктов и их категорий.
Проект содержит классы Category и Product, которые помогают реализовать списки продуктов по категориям.

### Новый функционал:

В проект добавлены новые классы:
- `Smartphone` - отвечает за предоставление информации о смартфоне:
его производительность, модель, объём памяти и цвет.
- `LawGrass` - отвечает за предоставление информации о траве газонной:
её страна-производитель, срок прорастания и цвет.

Также добавлены проверки типов и совместимости сложения для 
методов `__add__` в базовом классе Product и `add_product` в классе Category.

## Установка:

1. Клонируйте репозиторий:

`git clone git@github.com:Dmitriy-Logvinenko/E-commerce-OOP.git`

2. Установите зависимости:

`pip install -r requirements.txt`

## Использование:

1. Откройте свой терминал.
2. Запустите проект с помощью команды:

`python src/main.py`
